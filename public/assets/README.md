# Assets checklist

Paths are defined once in `src/constants/assets.ts`. Put your files here with these names
(or edit that file if you prefer different names).

```
public/assets
├── icons
│   ├── tech      html.svg  css.svg  javascript.svg  typescript.svg  sequelize.svg  mongodb.svg
│   └── social    facebook.svg  instagram.svg  linkedin.svg  tiktok.svg   (white icons, 16px)
└── images
    ├── hero          avatar.png (portrait, transparent bg)   brush.png (teal brush stroke)
    ├── about         photo.jpg
    ├── portfolio     portfolio-1.jpg  portfolio-2.jpg  portfolio-3.jpg
    ├── logos         airbnb.svg  dribbble.svg  zoom.svg
    ├── testimonials  avatar.jpg
    ├── faq           avatar.jpg
    └── footer        glass-board.png   (footer glass board background)
```
